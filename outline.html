Project Initiation: Teaching & Learning System

Project Name: Interlectic (Teaching Platform)

Development Environment: Agy (Terminal-based development)

Phase: MVP (Minimum Viable Product) / Startup Phase

Target Markets: Phase 1: Macau | Phase 2: Mainland China & Global

1. Project Goals & Objectives

▼

Primary Goals (MVP - Macau Focus):

  • Launch an MVP: Create a functional online platform that connects educators and learners.
  • Frictionless Onboarding: Implement a robust account system supporting Email/Password and SMS (Phone Number) verification, localized for Macau (+853) initially.
  • User Acquisition: Attract early adopters by offering a frictionless entry point via a 30-day free trial.
  • Multi-Language Support (i18n): Implement UI localization for three core languages from the start: Traditional Chinese, Simplified Chinese, and English.

Secondary Goals (Startup Phase constraints):

  • Defer Payment Gateways: Delay integration of local payments (MPay, Alipay, WeChat Pay) until post-trial validation.
  • Terminal-First Development: Utilize the Agy environment efficiently for rapid prototyping and backend structuring.
  • "China-Ready" Architecture: While Macau is open internet, build the architecture so it doesn't rely heavily on blocked external resources (e.g., Google APIs) so the transition to Mainland China is seamless.

2. System Architecture & Features (MVP Scope)

▼

A. Account Management (Core)

  • User Roles: Admin, Educator (Teacher), and Learner (Student).
  • Authentication: Dual-method authentication structure: SMS/Phone Login and Email/Password.
    Macau Note: Phone logins (+853) are standard, but email is also acceptable. We must support both.
  • Trial Logic: A background process tracking the account creation date to calculate the 30-day expiration.

B. Teaching Module (Educator Facing)

  • Course Creation: Ability to create a course title, description, and syllabus.
  • Content Upload: Functionality to add text, links, or upload essential files (PDFs).
  • Student Roster: View enrolled students.

C. Learning Module (Learner Facing)

  • Course Catalog/Dashboard: View available courses or enrolled courses.
  • Content Access: View materials uploaded by the educator.
  • Basic Progress: Simple marking of lessons or modules as "complete".

D. Localization Module (i18n)

  • Language Toggle: A user-facing dropdown to seamlessly switch the entire platform interface between English, Traditional Chinese (繁體中文), and Simplified Chinese (简体中文).
  • System Architecture: Keep all UI text (buttons, menus, email templates) in separate language files rather than hardcoding them into the pages, making it easy to manage translations.

3. Recommended Tech Stack

▼

This stack is chosen for rapid MVP development using terminal tools (Agy), high scalability for your revenue goals, and readiness for the Chinese market.

Frontend (User Interface)

Recommendation: Vue.js (with Nuxt.js) OR React (with Next.js)

  • Why Vue.js? Vue is massively popular in Asia. It has a massive ecosystem of UI libraries.
  • Why Nuxt/Next? Server-Side Rendering (SSR) is crucial for SEO and faster initial load times.
  • i18n Ready: Both frameworks have excellent libraries specifically for managing languages.
  • Rule for Future-Proofing: Try to host static assets locally rather than relying on Google CDNs.

Backend (Server Logic)

Recommendation: Node.js (TypeScript)

  • Why Node.js? Allows you to use JavaScript/TypeScript for both frontend and backend. Runs incredibly efficiently on low-power hardware like your M9.

Database

Recommendation: MySQL or PostgreSQL

  • Why? Highly structured, relational data (Users -> Enrollments -> Courses -> Payments).

Infrastructure & Hosting (Phase 0)

Self-Hosted on Morefine M9 N100

  • Hardware: The Intel N100 is perfect for a startup home-server running Linux.
  • Solution: Use Cloudflare Tunnels or frp routed through a cheap VPS to safely expose your Morefine M9 to the internet.

4. Proposed Technical Structure

▼
  • /app - Main application directory
    • /models - Database schemas
    • /controllers - Core logic (Auth, TrialValidation)
    • /views - Initial basic UI.
    • /locales - JSON files for en.json, zh-HK.json, and zh-CN.json.
  • /config - Database connection strings, environment variables.
  • /scripts - Terminal scripts for Agy to run migrations.

5. Post-MVP Roadmap

▼

Phase 2: Mainland China Expansion & Monetization

  • Infrastructure Migration: Move the database and backend from the M9 to Alibaba Cloud or Tencent Cloud.
  • Localized Payment Gateways: Integrate MPay (for Macau) alongside WeChat Pay and Alipay.
  • Subscription Models: Tiered pricing (e.g., Basic, Pro).

Phase 3: Advanced Features & Retention

  • Native Video Hosting: Upload and stream video lectures using regional CDNs.
  • Interactive Learning: Quizzes, assignments, and certificates.
