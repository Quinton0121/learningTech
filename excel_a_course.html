To tell Excel you want it to act as a calculator, you must start with an equals sign (=). This is called Syntax.

The Golden Rule COUNT vs COUNTA

COUNT ignores text. If a student wrote "N/A", "Absent", or "Lost", COUNT skips it entirely!

COUNTA stands for "Count All". It counts any cell that is not completely blank (numbers, words, symbols, errors).

Formula: =COUNTA(range) - COUNT(range)
➔ Returns exact count of text-only notes!
